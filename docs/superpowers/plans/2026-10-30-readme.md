> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current promotional README with an operations-first, source-verified guide for installing, protecting, and contributing to Fortress.

**Architecture:** Keep one root `README.md` as the entry point and link to existing detailed documentation instead of duplicating it. Separate local setup, production operation, managed Windows clients, security and recovery, and contributor verification into short sections grounded in repository source.

**Tech Stack:** Markdown, Bun 1.4.x, React 19, TypeScript, Vite 6, Express 5, SQLite or PostgreSQL, Docker Compose.
